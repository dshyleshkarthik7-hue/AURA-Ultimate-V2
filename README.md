# AURA Perception V2

Offline-first, privacy-preserving Indian multilingual object-recognition prototype.

## Objects
Steel Glass, Steel Water Bottle, Bottle Gourd.

## Languages
English, Hindi, Telugu, Tamil, Gujarati.

## Architecture
The Python perception stack runs locally with NumPy/OpenCV and a from-scratch classifier. The browser uses the same 329-value feature definition and local model artifact. The web demo also uses COCO-SSD from a CDN for person filtering; therefore the web demo remains network-dependent for that optional detector.

The browser now applies a captured-background motion region, suppresses regions overlapping detected people, uses the same feature arithmetic as Python, provides position/size guidance, and captures front/left/right/final evidence views before reporting a verified result.

Training uses balanced class weights, session-safe splits, validation temperature calibration, bootstrap 95% accuracy intervals, and explicit unknown-object evaluation when an independently collected `dataset/unknown/` set is supplied. Automatic retraining is guarded self-training: multi-view agreement is required and a frozen-teacher regression gate protects the active model.

## Quick start
1. Create and activate a Python virtual environment.
2. `pip install -r requirements.txt`
3. `python -m unittest discover -s tests -p "test*.py"`
4. `python train.py`
5. `python evaluate.py`
6. `python scripts/generate_model_card.py`
7. `python app.py`

After changing `config.yaml`, run `python scripts/export_web_config.py`.

## Evaluation discipline
Augmented frames are never treated as independent evaluation evidence. For deployment claims, collect independent camera sessions and an independently labelled unknown-object set. Pseudo-label self-training is not ground-truth labelling.

For the browser, the seven-frame temporal signal is not treated as seven independent photographs: final verification additionally requires four view captures (front, left, right, final). This is still user-guided multi-view evidence, not a substitute for a professionally labelled benchmark.

## Dataset
`dataset/MANIFEST.csv` is checked by CI against committed JPEG counts and regenerated by training. The current dataset is imbalanced; training compensates with balanced class weights. Additional independent sessions remain necessary.

## Model card
`MODEL_CARD.md` records the evaluation structure and can be regenerated after each measured evaluation.

## Browser limitations
The browser feature implementation is intentionally kept in lockstep with `aura/features.py`; the contract validator checks the 329-feature/model/config relationship and required perception stages. Browser performance and accuracy still need measurement on representative hardware before production claims.
